# 规则测试清单
状态默认未验证；未确认QQ行为为pending。
- JQL：头部、长度、非法编码、数量、空营位、旗/雷/炸布局；普通等级互换不能被布局合法性证明。
- 拓扑：每国30点、中央点、道路/铁路区别、对称性、弧线；129点不是唯一正确性依据。
- 移动：公路一步；铁路阻挡；工兵转弯；普通子允许与禁止转向；友军占位；营地保护；本营不动。
- 碰撞：各等级顺序、同级、工兵雷、炸弹雷、炸弹旗、主动与被动司令阵亡。
- 轮次：四座位轮转、首家、出局后跳过；无子可走、投降、扛旗清场、团队终局。
- 判和：阈值前/等于/后；碰撞重置；同归于尽；计数单位；终局优先；截断不是和棋。
- 状态：非法走法不改变状态；走子撤销逐字段一致；棋子总账（存活/阵亡/清场）守恒。
- 观察：自己的身份可见，队友和敌方隐藏；公开揭示事件；合法动作不能暴露他方身份。
- 隔离：同观察、配置、种子、固定预算下改变真实暗子，随机策略输出一致。
- 回放：完整私有日志重建；观察回放过滤；序号断裂、损坏尾行、配置不符明确拒绝或标不完整。
- 差分：第三方不可用时未验证，分歧记录而非强行对齐。

- 真实棋谱对照：格式/坐标映射错误与规则执行差异分开定位；记录第一处偏离、事件序号与匿名复现局面。缺证据不归因为玩家失误。
