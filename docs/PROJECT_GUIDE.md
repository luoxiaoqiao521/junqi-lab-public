## 模块索引

| 模块 | 职责 |

| [core](../core) | 棋盘拓扑、部署约束、合法着、步进、碰撞、轮转和结算。 |

| [sim](../sim) | 回放校验、单席学习入口、公开历史、候选和续局研究组件。可从 [主程序](../sim/main.cpp) 查看现役命令。 |

## 当前验证边界

- 训练链路已经支持单席权重更新、保存、重载、冻结陪练与成对续局。练习二进制默认使用启发式，独立研究模型另由实验入口加载。对独立完整开局的稳定棋力增益仍需实证。
- 本地脚本实验可以固定一手进行配对裁判。相同公开历史的兼容暗盘可以产生不同的护旗与终局结果。训练标签要保留未决、估计范围及适用陪练条件。
- 最近一张本机回执为第 743–745 轮，主题是归因公开旗险和攻守兑现。下一票沿真实轮转定位更早的可改点，检查本席、对家、攻击方转线和已在四着内但排序靠后的防守。
- 原始文件读取、规则取值验证和训练数据接入分开。原本机调度合同、回执、棋谱和冻结模型留在本机。某些研究脚本仍以本机历史档案或模型输出为输入，需要按该脚本的实际合同配置。当前快照没有完成这些素材依赖的实验复验。

## 评估口径

冻结裁判、观察、席位策略、预算和随机流。成对对照只改变一个干预，按来源布局分组，报告真实实选、胜和负及截断。脚本前景、局部保旗或短窗碰撞不能单独定义团队收益。规则差异和隐藏信息边界应在比较前核查。
