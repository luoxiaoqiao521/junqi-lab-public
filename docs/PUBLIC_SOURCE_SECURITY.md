# 本地与公开边界

公开源码快照使用经过检查的独立 Git 历史。原谱、原谱文件名、真人资料索引、本机路径配置、逐局记录、模型和调度凭据留在本机。公开源码从 [项目入口](PROJECT_GUIDE.md) 查找。

- 历史回放研究若确有需要，在 Git 忽略的 `build/private/archive-inputs.json` 中读取选中源谱、试验组、指定归档成员或系列标识。公开快照没有这个文件。失败信息避免回显该清单中的值。
- 旧 JQH 候选研究只读取 `build/private/jqh-candidate-input.json` 被动数据。文件格式为版本 `schema: 1`，`cases` 每项含匿名 `key`、三整数一行的 `pieces` 和五整数一行的 `events`。裁判仍负责合法性和终局。历史复盘不在此次运行范围里。
- 本地调度只在本机处理现役合同。源码仓库无需本机调度配置即可构建验证。公开仓库无需连接本机调度、Webhooks、部署密钥或自托管执行器。
- 数据文件与合成发布测试区分。工程回归可在被忽略目录本机生成种子对局。仅将源码和经检查的说明同步至公开仓库。
